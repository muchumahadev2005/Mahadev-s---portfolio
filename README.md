# Muchu Mahadev — Software Developer Portfolio

An award-winning caliber interactive portfolio engineered with React 18, Three.js, GSAP, and Tailwind CSS, featuring immersive WebGL shaders, magnetic physics, and live Web3Forms contact transmission.

## 🚀 Live Demo
- **Repository**: [Mahadev-s---portfolio](https://github.com/muchumahadev2005/Mahadev-s---portfolio)

## ✨ Tech Stack & Features
- **Frontend Architecture**: React 18, Vite, Tailwind CSS
- **Creative & 3D**: Three.js custom particle field and shader lighting
- **Animation & Interactions**: GSAP ScrollTrigger, Lenis smooth scrolling, Framer Motion, canvas-confetti
- **Transmission System**: Direct serverless delivery to inbox via Web3Forms API
- **Responsive**: Engineered with desktop, tablet, and mobile-first micro-interactions

## 🛠️ Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/muchumahadev2005/Mahadev-s---portfolio.git
   cd Mahadev-s---portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment**:
   Copy `.env.example` to `.env` and configure your Web3Forms access key:
   ```bash
   cp .env.example .env
   ```

4. **Start Development Server**:
   ```bash
   npm run dev
   ```

5. **Build for Production**:
   ```bash
   npm run build
   ```
